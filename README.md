# MarketPro — نسخة أندرويد

تطبيق محاسبة ونقطة بيع للسوبر ماركت (نسخة الهاتف من MarketPro).

- نفس محرك الحسابات في نسخة الكمبيوتر (`com.market`): الفواتير، المخزون، الذمم، الصندوق، القيود.
- قاعدة بيانات SQLite محلية على الهاتف، ويمكن نقل نسخة `.db` بين الكمبيوتر والهاتف.
- الشاشات: البيع والشراء والمرتجعات والطلبيات، سجل الفواتير، الأصناف والجرد، العملاء والموردون وكشف الحساب، الصندوق، المصاريف، التقارير، الإعدادات، النسخ الاحتياطي.
- قراءة الباركود بالكاميرا.

## البناء
يُبنى ملف APK تلقائياً عبر GitHub Actions (`.github/workflows/build-apk.yml`) ويُرفع كـ Artifact باسم `MarketPos-debug-apk`.
محلياً: `gradle :app:assembleDebug`.
